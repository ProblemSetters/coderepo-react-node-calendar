# Feature: Calendar Views

`Medium`

## Overview

**Skills:** React (Intermediate), Code Repository
**Recommended Duration:** 60 minutes

Implement Calendar's responsive Day, Week, and Month workspace with familiar navigation and accurate item placement.

## Product Requirements

- Navigate with Today, previous/next controls, and the mini calendar.
- Render timed, overlapping, all-day, cross-midnight, and multi-day items.
- Use a 12-hour clock, local GMT offset, current-time indicator, and responsive sidebar.
- Preserve view and sidebar preferences without horizontal page overflow.

## Steps to Test Functionality

- Run `bun install` and `bun start`.
- Verify navigation and seeded items in every view.
- Resize to 390 pixels and confirm the calendar remains usable.

**Note:** Review `technical-specs/CalendarViews.md` for the complete contract.
