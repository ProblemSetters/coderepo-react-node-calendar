# Feature: Calendar Management and Search

`Medium`

## Overview

**Skills:** React, Express, MongoDB (Intermediate), Code Repository
**Recommended Duration:** 60 minutes

Implement calendar organization and advanced event discovery without losing the current calendar context.

## Product Requirements

- Create, rename, recolor, show, hide, and display a calendar exclusively.
- Protect primary and non-empty calendars from unsafe deletion.
- Open search compactly and reveal advanced filters only on request.
- Combine scope, text, participant, location, exclusion, and local date filters.

## Steps to Test Functionality

- Create and modify a secondary calendar.
- Exercise deletion protections and display-only mode.
- Run quick and advanced searches against active and all calendars.

**Note:** Review `technical-specs/CalendarManagement.md` and `technical-specs/EventManagement.md`.
