# Feature: Time Insights

`Medium`

## Overview

**Skills:** React, Node.js, Data Aggregation (Intermediate), Code Repository
**Recommended Duration:** 50 minutes

Implement a server-computed daily view of how calendar time is allocated.

## Product Requirements

- Show meeting duration, trailing average, and working-day load.
- Provide By type and By calendar drawer breakdowns.
- Clip timed items, cap all-day Out of office, and exclude Working location metadata.
- Refresh after date, visibility, create, update, and delete changes.

## Steps to Test Functionality

- Open More insights and switch both breakdowns.
- Verify empty, over-capacity, and cross-boundary days.
- Schedule Focus time and confirm totals refresh.
